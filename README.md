# NYX-SOLUCTION

A NYX, é um grupo de TI criado no segundo semestre de 2026. Com o objetivo de desenvolver um projeto para uma empresa com prazo de 5 semestres corridos.

* Empresa escolhida:
Neste momento já temos a empresa onde prestaremos nossos serviços, ela se chama Arvo. A Arvo é uma healthtech brasileira, que utiliza Inteligência Artificial e dados para garantir a integridade de pagamentos e a eficiência das auditorias de operadoras de saúde. A empresa atua como parceira do setor para otimizar gastos e garantir a sustentabilidade do ecossistema médico.

* Projeto a ser desenvolvido:
O projeto consiste na criação de uma web fechada, para fazer mapeamento e análise de eventos nacionais e nos EUA. A Web vai ter o objetivo de facilitar na busca de eventos e na análise de relevancia para empresa.
